# 고전 만화 캐릭터 사진 검수

Wikimedia의 퍼블릭 도메인 이미지 후보를 전체 썸네일로 육안 검수했다. 캐릭터 식별 가능 여부와 사진 안의 정답 직접 노출을 확인했다.

## 출제 승인

- 피터 팬: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 펠릭스 더 캣: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 코코 더 클라운: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 크레이지 캣: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 버스터 브라운: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 캐터필러: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 겁쟁이 사자: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 매드 해터: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음
- 하트 여왕: 캐릭터가 식별 가능하고 정답 텍스트가 직접 드러나지 않음

## 제외

- 리틀 니모: 말풍선에 정답 이름이 직접 보여 제외
- 머트와 제프: 포스터 제목에 정답이 직접 보여 제외
- 거티: 포스터 제목에 정답이 직접 보여 제외
- 파머 알 팔파: 캐릭터 식별이 어려워 제외
- 플립 더 프로그: 포스터 제목에 정답이 직접 보여 제외
- 캣젠재머 키즈: 제목이 이미지에 직접 보여 제외
- 보스코: 검은 화면으로 확인돼 제외
- 험프티 덤프티: 표지 제목에 정답이 직접 보여 제외
