# 삼삼오오

여럿이 모여 큰 화면에 뜬 사진을 보고 5초 안에 이름을 맞히는 웹 파티 게임.

현재 단계는 **싱글·대결 버전 구현·배포 완료**입니다. 게임 화면은 `dist/`, 방과 실시간 판정 서버는 `server.mjs`에 있습니다.

공개 주소: <https://maru4737.duckdns.org/samsam/>

- [기획 및 구현 인계 문서](./docs/PRODUCT_SPEC.md)
- [싱글·대결 모드 기획 및 구현 설계](./docs/MULTIPLAYER_DESIGN.md)
- 인물 버전, 사물 버전, 인물·사물 혼합 버전 제공
- 인물 버전은 전체·국내·해외·만화/동화 캐릭터 항목 선택 가능
- 싱글·대결 모두 인물 항목을 인물 버전 오른쪽에서 선택
- 싱글 한 판은 5·10·15·20문제, 문제당 제한 시간은 3·5·10·15·20·30초 중 선택 (기본 10문제·5초)
- 출처와 라이선스를 확인하고 14장의 전체 썸네일 시트로 육안 검수한 로컬 사진
- 같이 외치기: 모여서 답을 외친 뒤 진행자가 정답·패스를 선택
- 직접 입력하기: 선택한 제한 시간 안에 정답을 적고 Enter를 누르면 자동 판정하며, 정답이면 즉시 다음 문제 출제
- 무작위 출제, 한 번 나온 문제 뒤로 보내기, 5초 타이머, 큰 화면 모드
- 모바일 키보드가 열리면 실제 보이는 화면 높이에 맞춰 사진을 줄이고 점수판·버튼을 간결하게 표시. 키보드를 닫으면 사진 영역을 다시 확장
- 3·2·1 카운트, 정답·오답·패스·시간 종료 효과음과 음소거 버튼
- 메인에서 싱글 버전·대결 버전을 선택
- 대결 버전: 방 생성, 초대 링크·코드 참가, 준비, 방장 시작, 먼저 맞힌 한 명만 득점
- 방장은 준비 버튼 없이 시작 버튼만 사용. 두 명 이상 접속하고 방장 외 모든 참가자가 준비를 마쳐야 시작 가능
- 대결 시작 전 모든 참가자가 선택한 사진 전체를 내려받고 디코딩한 뒤 준비 완료를 서버에 알림. 전원 완료 후 시작 카운트다운을 진행하며, 문제 사이에는 추가 로딩 대기를 넣지 않음
- 한 명이라도 사진 준비에 실패하면 같은 대체 문제 묶음을 전원에게 보내 다시 확인. 준비 중 연결이 끊기거나 60초 내 준비를 마치지 못하면 점수 변경 없이 대기실로 복귀
- 대결은 단일 Node 서버가 방·타이머·정답·점수를 판정하며, 서버 재시작 시 진행 중인 방은 종료
- [사진 검수 기록](./docs/IMAGE_REVIEW.md)

## 실행

별도 npm 의존성은 없습니다. `node server.mjs`가 `dist/`의 화면·사진을 제공하고 WebSocket 대결방을 함께 처리합니다.

대결 회귀 검증: `PORT=4173 node server.mjs` 실행 후 `node scripts/test-battle.mjs`. 느린 참가자, 사진 대체, 이전 준비 응답 무시, 5문제 동시 정답 판정, 재대결 및 연결 종료를 검사합니다. `TEST_PRELOAD_TIMEOUT=1 node scripts/test-battle.mjs`는 준비 시간초과 복귀도 검사합니다.

Kubernetes 배포는 `scripts/deploy-k8s.sh`가 Node 이미지를 만들고 노드의 containerd에 적재한 뒤 `k8s/samsam.yaml`을 적용합니다. 내부 서비스 포트는 `31083`이고, 서버 Nginx가 `infra/nginx/samsam-location.conf`로 공개 경로 `/samsam/`과 WebSocket 업그레이드를 이 포트에 연결합니다. 방 상태는 메모리에 있으므로 Deployment replica는 1개로 유지합니다.

문제 사진은 빌드 전에 Wikimedia Commons에서 내려받아 `dist/assets/images/`에 저장하고 WebP로 최적화합니다. 게임 중에는 외부 사진 서버에 접속하지 않으며, 사진별 출처·저작자·라이선스는 게임의 `사진 출처 보기`에서 확인할 수 있습니다.
