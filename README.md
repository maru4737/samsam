# 삼삼오오

여럿이 모여 큰 화면에 뜬 사진을 보고 5초 안에 이름을 맞히는 웹 파티 게임.

현재 단계는 **구현 및 배포 진행 중**입니다. 게임 소스는 `dist/`에 있으며, 정적 웹앱으로 배포합니다.

- [기획 및 구현 인계 문서](./docs/PRODUCT_SPEC.md)
- 첫 버전: 연예인 이름 맞히기, 사물 이름 맞히기, 무작위 출제, 중복 출제 지연, 5초 타이머, 큰 화면 모드

## 실행

별도 빌드나 의존성 설치가 필요 없는 정적 웹앱입니다. `dist/index.html`을 정적 웹 서버로 제공하면 됩니다.

연예인 사진은 실행 중 한국어 위키백과의 공개 요약 API에서 가져옵니다. 통신 실패 시에도 문제를 건너뛰지 않고 대체 화면으로 진행합니다.
